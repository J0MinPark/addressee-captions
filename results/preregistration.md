## 1. 시연 구성 선택 규칙 (dev에서만)

- **정확도 기준**: AI Hub 반합성 **dev**, 조건 **(single_mic, Y −6 dB, SNR 10 dB)**, 정답 정의 **"내 대화" = 라벨 x**(착용자와 같은 대화의 다른 참가자), 지표 **F0.5**.
  - 양성 = x, 음성 = y(옆 대화). 착용자 구간(w)과 unmatched(겹침 50% 미만)는 지표에서 뺀다.
  - 예측 양성 = 크게 표시(partner). 시나리오 12개를 합산한 정밀도·재현율로 F0.5를 계산한다.
- **제약 1**: 같은 조건에서 **자연 함정 오표시율이 timing 모드보다 낮다**(점추정).
  - 자연 함정 = 착용자 발화 종료 후 1.5초 안에 시작한 y 발화에 연결된 시스템 구간. 오표시율은 그중 크게 표시된 비율이다.
- **제약 2**: **원격 경로로 잰 자막 지연 p95 ≤ 2초**.
  - 사람이 Book5에서 `tools/latency_bench.py --remote`로 재서 준다("최종" 지연 = LLM 판정 반영까지).
  - 측정값이 없으면 서버 localhost 측정값으로 잠정 선택하고, **잠정**임을 결과 문서와 시작 로그 구성 이름 옆에 적는다.
  - 지연은 구성마다 다를 수 있으므로 LLM을 쓰는 구성과 쓰지 않는 구성을 각각 잰다(같은 판정기·같은 모델이면 같은 값으로 본다).
- **선택**: 두 제약을 만족하는 후보 중 F0.5 최대.
  - 동률(소수 셋째 자리까지 같음)이면 더 단순한 쪽을 고른다. 순서: timing 계열 < 손 가중치 < 학습된 융합, 플래그 적은 쪽.
  - 만족하는 후보가 없으면 **timing 모드를 배포**하고 시연 런북에서 함정 장면을 뺀다.
- **적용**: `tools/apply_selection.py`가 이 규칙의 결과(`results/demo_selection.json`)만 `app/demo_config.yaml`로 시연 프로필에 적용한다. 근거는 `results/demo_selection.md`에 남긴다.

## 2. 후보 풀

- **판정기**(한국어판, qwen3:4b): P1c(v1) · P1(2026-10 버그 수정판, `results/ko_prompt_fix.md`) · P2 · P3.
- **융합**:
  - 손 가중치(config 기본값).
  - AI Hub dev에서 새로 학습한 L2 로지스틱(특징·학습 코드는 AMI와 같음, `tools/tune_dev.py`).
    - 정규화 강도 C ∈ {0.01, 0.1, 1, 10, 100}과 임계값 0.10–0.85(0.05 간격)는 학습 겹 안에서 고른다.
    - 교차검증 단위는 **(세션, 착용자)**, 6겹이다. 선택에는 **겹 밖(out-of-fold) 점수**만 쓴다.
    - 배포 가중치는 dev 전체로 다시 학습한다. 학습 데이터는 dev 8개 조건 합산이다.
  - AMI에서 학습한 가중치는 후보에서 뺀다.
- **플래그**: `--candidate-rejudge`, `--short-skip-llm`(각각 끔/켬, 4조합).
- **LLM 없는 모드**: timing, timing_speaker.
- **기준선**: all(전부 표시), timing, v1(P1c · 손 가중치 · 플래그 없음).

## 3. 데이터 구성 (고정값)

- **라벨**: TL1–TL7(filekey 61634–61640), VL1(563185). **원천**은 Training 묶음 하나만 받는다.
  - 선택 규칙: 후보 세션 40개 이상인 묶음 중 원천 zip이 가장 작은 것. 없으면 후보가 가장 많은 묶음.
  - 라벨 TLn ↔ 원천 TSn이 같은 번호끼리 대응한다고 가정한다(받기 전에는 확인할 방법이 없다. 받은 뒤 파일명으로 확인해 보고한다).
- **후보 세션 필터**(`tools/aihub_select.py`):
  - speaker_num 3–4.
  - 다른 화자 구간이 0.3초 이상 겹치는 발화 비율 ≤ 20%.
  - 착용자로 쓸 화자가 10분 구간 안에서 발화 15회 이상.
  - 우선순위: media 독서토론 > 회의 > 온라인회의 > 토론 → relation "사회자 없이 토론자" → environment 태그 발화 비율이 낮은 순.
- **반합성 시나리오**(`tools/aihub_mix.py`, 시드 고정 20261002):
  - **X(내 대화)**: 한 세션의 10분 구간. 착용자 1명은 그 구간에서 발화가 가장 많은 화자.
  - **Y(옆 대화)**: 다른 세션의 10분 구간, 시작 오프셋 무작위.
  - 같은 세션은 X와 Y로 동시에 쓰지 않는다. dev와 test는 세션이 겹치지 않는다(`splits_aihub.json`).
  - **채널 B** = X + Y(X 대비 −6 dB, −10 dB) + DEMAND PCAFETER(SNR 10 dB, 5 dB). 레벨은 정답 발화 구간 RMS 기준.
  - **채널 A**: 착용자 발화를 원천 그대로(헤드셋 대용). oracle 조건만 쓴다. single_mic 조건은 B만 쓴다.
  - **라벨**: w = 착용자, x = X의 다른 참가자, y = Y의 발화. 시스템 구간은 시간 겹침이 가장 큰 발화에 연결한다. 겹침이 구간 길이의 50% 미만이면 unmatched로 빼고 개수를 보고한다.
  - **자연 함정**: 시나리오당 5개 미만이면 Y 오프셋을 다시 뽑는다(최대 5회). 그래도 미만이면 그대로 쓰고 보고한다.
  - 시나리오 수: **dev 12, test 12**.
  - 한국어 프로필: ASR ko, 한국어 판정 프롬프트, 호명 감지 끔, 위험 소리 끔(평가와 무관).
- **본인 발화 조건**:
  - oracle: 착용자 구간을 정답 시간으로 준다(판정 로직만 평가).
  - single_mic: 단일 마이크 모드. 착용자 등록 음성은 같은 세션의 평가 구간 밖에서 착용자 발화 10초를 가져온다.
- 조건 격자: 본인 발화 2 × Y 음량 2 × 소음 2 = **시나리오당 8조건**. 주 조건은 1절의 하나다.

## 4. 지표와 통계

- **지표**: 정밀도, 재현율, F0.5, 자막 오염도(크게 표시된 글자 중 y 비율), 자연 함정 오표시율, 옆 대화 화자 오등록률(Y 화자가 partner로 등록된 비율).
- **표**: Y 음량 × 소음 × 본인 발화 조건별 표.
- **통계**: 핵심 비교(timing vs 선택 구성, v1 vs 선택 구성)에 **세션 단위 부트스트랩 1000회** 95% 신뢰구간과 짝지은 차이(같은 재표본)를 붙인다.
- **절차**: dev 시나리오 1개로 끝까지 돌려 표가 나오는지 확인한 뒤 전체를 돌린다.
